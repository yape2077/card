# Student ID Card Generator

A browser-based tool to generate printable Student ID cards formatted for A4 landscape Word documents (.docx) from Excel files.

## Features

- **6 Cards Per Page:** Generates an A4 landscape, scissor-ready grid layout.
- **Custom Header Note:** Add custom notes (such as school name or branch address) to the top-right header.
- **Blank Template Download:** Get a ready-to-use `.xlsx` template directly from the interface.
- **100% Client-Side:** All processing happens locally in your browser. Your student files and personal data are never uploaded to any remote server.
- **Dark / Light Theme:** Switch between visual themes with a single click.

## How to Run

1. Click the green **Code** button at the top of this GitHub repository.
2. Select **Download ZIP**.
3. Extract the downloaded `.zip` file on your computer.
4. Double-click `index.html` to run it directly inside your web browser.

## Required Excel Format

The uploaded file (`.xlsx` or `.xls`) must contain these exact column names in the first sheet:
- `Child Name`
- `Child ID`
